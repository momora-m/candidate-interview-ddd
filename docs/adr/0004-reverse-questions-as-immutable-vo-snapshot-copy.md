# ADR-0004: 逆質問の面接割当における「不変スナップショットコピー（VO）」方式の採用

- **ステータス**: 承認 (Accepted)
- **決定日**: 2026-10-17

## コンテキスト (Context)
候補者は、企業調査を通じて蓄積した「全社逆質問プール（StockedReverseQuestion）」から、特定の面接（一次面接・役員面接など）の担当者ロールに合わせて逆質問を割り当てる。
この面接に割り当てられた質問（AssignedReverseQuestion）のデータモデルとして、以下の2案を比較検討した：

- **案1: 参照方式（Entity ID 参照）**: 面接エンティティからは質問IDのみを保持し、マスタ質問を参照する。
- **案2: 不変スナップショットコピー（Value Object）方式**: 割当時にマスタ質問の文面・意図・対象ロールをディープコピーし、面接専用の独立したスナップショットとして保持する。

## 決定事項 (Decision)
**案2（不変スナップショットコピー / 値オブジェクト）を採用する。**

`StockedReverseQuestion` から `AssignedReverseQuestion` へ変換するファクトリメソッド（`AssignedReverseQuestion.fromStocked(...)`）を提供し、面接固有の以下のライフサイクルを持たせる：
1. 面接前: 質問内容のスナップショット + 優先度（Priority 1〜5）設定
2. 面接中・後: 実際に面接官から得られた回答の記録（`AnswerRecord`）および候補者による納得感・回答満足度スコア（1〜5）の付与

## 影響とトレードオフ (Consequences)
- **メリット**:
  - **過去の面接記録の改ざん防止**: マスタ側の質問文を後から推敲・編集・削除しても、過去の面接で「実際に何を聞き、どう回答されたか」という面接履歴（タイムカプセル）が一切破壊されない。
  - **面接向けカスタマイズの自由度**: 面接官の肩書（CTO、人事、現場リーダー）に合わせて、マスタの質問文を微調整して割り当てることが可能。
  - **値オブジェクトとしての自己完結性**: 回答記録（AnswerRecord）も不変値オブジェクトとして扱え、等価性比較が容易。
- **トレードオフ**:
  - マスタ質問を修正しても、過去・現在割り当て済みの質問には自動伝播しない（ただし、これはドメイン要件として望ましい挙動である）。
